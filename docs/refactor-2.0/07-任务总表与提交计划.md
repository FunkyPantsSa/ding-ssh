## 7. 提交计划（按分支）

### 7.1 分支与合并

| 分支 | 起点 | 合并条件 | 合并方式 |
|---|---|---|---|
| `feat/ui2-p0` | `main` | M0 门禁 | 直接 merge（只含 docs/scripts） |
| `feat/ui2-p1` | `feat/ui2-p0` 合入后的 `main` | M1 门禁 + P1-21 回归 | `--no-ff` |
| `feat/ui2-p2` | P1 合入后的 `main` | M2 门禁 + 六档缩放 | `--no-ff` |
| `feat/ui2-p3` | P2 合入后的 `main` | M3 门禁 + Go 测试 | `--no-ff` |
| `feat/ui2-p4` | P3 合入后的 `main` | M4 门禁 + 三平台 | `--no-ff`，打 tag |

### 7.2 提交粒度规则

1. 一个提交 = 一个可独立构建、可独立 revert 的变更。
2. 提交信息：`type(scope): 中文摘要`，body 包含「现象 / 原因 / 改法 / 验证」四段（与 `CHANGELOG.md` 风格一致）。
3. 迁移、旧别名删除、选择器切换各自单独提交，不与其他改动混合。
4. 每个阶段最后一个提交必须是 `test(ui): ...回归记录`，附快照名与结果。
5. 禁止把 `package-lock.json` 与业务代码混在同一提交（依赖变更单独提交）。

示例：

```text
refactor(theme): 拆分三层设计令牌

现象：style.css 117 处变量混在一起，组件直接引用 --ink-*，换主题需全局搜索。
原因：缺少 primitive/semantic/component 分层，旧变量没有别名。
改法：新增 theme/tokens.css、semantic.css、components.css、aliases.css；
      style.css 只保留 base 与极少量 utilities。
验证：npm run build 通过；ui.tokens 中 --background/--primary 生效；
      13 组快照 diff 仅颜色变化，无布局位移。
```

## 8. 关键路径与并行建议

```text
关键路径：
P0-02 → P1-02 → P1-03 → P1-05 → P1-11 → P1-14 → P2-01 → P2-02 → P2-07
→ P2-19 → P3-13 → P3-15 → P3-21 → P4-06 → P4-07 → P4-08 → P4-12

可并行：
- P1-07/08（字体） ∥ P1-01~05（令牌）
- P1-11/12（组件） ∥ P1-15/16（引擎）
- P2-04/05/06（顶栏/侧栏/状态栏） ∥ P2-07（终端区）
- P3-05~09（Servers） ∥ P3-10~12（Tunnels）
- P3-13（Transfers 数据） ∥ P3-15（Settings 壳）
- P4-11（文档） ∥ P4-09/10（性能/三平台）
```

**不要并行**：

- P2-01~10 的 `App.vue` 拆分（同一文件，冲突成本极高）。
- P3-15~20 的 Settings 拆分（同一文件，必须按分区串行提交）。
- P4-07 旧别名删除与任何功能改动（必须单独提交，便于回滚）。

## 9. 状态维护与节奏

| 节奏 | 动作 |
|---|---|
| 每日 | 更新本文「状态」列；收工前跑 `npm run build` + 相关页面冒烟 |
| 每周 | 阶段分支 rebase `main`；跑一次 `go test ./internal/...`；更新风险登记 |
| 每个 WP 结束 | 写一条 `ui.snapshot` + 截图；在验收单打勾 |
| 每个阶段结束 | 完整门禁 + 记录 + 合入 `main` + 打里程碑 tag（`ui2-m0`…`ui2-m4`） |
| 发布前 | 用旧 `settings.json` 升级演练 + 降级演练 + 三平台冒烟 |

### 任务状态定义

| 状态 | 含义 |
|---|---|
| `待开始` | 未动工 |
| `进行中` | 有分支/提交，未达验收 |
| `待验收` | 代码完成，等待门禁/评审 |
| `已完成` | 验收项全部通过并记录 |
| `已阻塞` | 记录阻塞原因与解除条件（不允许长期停留） |

> 建议在本文表格中加一列「状态」并在执行时维护；也可以同步到 GitHub Projects，但**本文仍是唯一事实来源**。
