### 4.3 迁移字段（建议）

现状 Settings 没有版本号。为了只迁移一次、且旧版本降级后不破坏配置，建议新增一个**可选整型** `uiSchema`（默认 0）：

```go
// internal/models/models.go
UISchema int `json:"uiSchema"` // UI 规范版本：0/缺省 = 旧版；2 = Geist 2.0 已迁移
```

- Go `encoding/json` 会忽略未知字段，旧版本读新配置不会报错；但旧版本保存时会丢掉 `uiSchema`，因此迁移逻辑必须**幂等**（重复执行结果一致）。
- 迁移只做三件事：默认外观替换、语义着色默认值、旧主题备份；**不碰服务器/凭证/隧道/会话数据**。
- 备份写到 `localStorage` 的 `ding-ssh:ui2-migration-backup`（JSON，含迁移前的 `appearance/theme/fonts/terminalColorMode`），便于回滚排查。

## 9. 硬约束（任何阶段都不得违反）

1. **不改后端业务行为**：SSH 密码/私钥、分组、连接测试、自动重连、SFTP、目录双向联动、Zmodem、端口转发、SysInfo、传输限速/并发/取消、配置导入导出、主密码、调试 HTTP/SSE/MCP/审计——行为与 API 均不变。
2. **不换技术栈**：Wails v2、Go、Vue 3、TS、Pinia、Tailwind v4、xterm.js 6 不变；不引入 Vue Router、不引入第二套状态管理。
3. **不改 SQLite 数据模型**：服务器/凭证/隧道/分组的表结构与序列化不变；设置只允许**追加可选字段**。
4. **不降低自动化能力**：25 个 `ui.*` 工具、`ui.layout` 的 9 个关键区域、`ui.navigate`、`app.commands`、终端调试注册表必须持续可用。
5. **不绕过后端权限**：Debug 能力位、两段式确认、敏感操作校验仍在 Go 侧；UI 只做展示与触发。
6. **不删分屏、不做移动端优先**：分屏降级为高级功能但代码与状态保留；断点只服务桌面窄窗口（最小 900×600）。
7. **不为了视觉改终端渲染**：WebGL 优先/Canvas 降级、缩放补丁、IME 兼容、5000 行回滚、复制粘贴、右键行为不得回退。
8. **设置向后兼容**：新版本写出的 `settings.json` 被旧版本读取时不得崩溃、不得清空用户配置；迁移必须幂等。
9. **一次只改一层**：P1 不改业务组件结构，P2 不改页面内部，P3 不改外壳；跨层需求走契约变更流程。
10. **可回滚**：每个提交能单独 revert；每个阶段结束打 tag/记录基线快照。
