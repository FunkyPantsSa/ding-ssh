## 明确的边界

- 普通 SFTP 无法彻底消除远端其他进程造成的检查/写入竞态；追加写非原子，ACL/xattrs 不保证保留。任意 shell 可绕过 SFTP 白名单，强隔离依赖远端账号/chroot/受控代理。
- 取消 SSH channel 不保证远端整个进程树已终止；没有退出确认就报告 unknown。应用重启不保证任务继续运行，也不会自动重放命令。
- `confirm.prepare` 当前同步等待原生审批；`confirm.status` 查询批准后的执行凭据状态，不是异步审批收件箱。限时批准精确到完整参数，不提供通配命令授权。
- 任意 DOM/JS 和本机 shell 属于完全信任范围。运维预设允许远端任意命令，不能被描述为低权限沙箱。
- 像素截图目前仍仅 Windows 支持，工具目录明确标记；macOS/Linux 返回不支持原因。此次没有声称跨平台像素验证通过。
- TLS/OAuth 正式远程部署、目录级同步、可选 chmod/copy/search 等不属于本次核心实现；继续保留原方案中的后续评估项。当前远程接入仍应通过 SSH 转发；未新增不完整的远程认证方案。
